## Выполненная работа:

### 1. Настройка окружения
- Создан файл `.env.local` с переменной `BURGER_API_URL` для хранения URL API

### 2. Настройка Redux store
- Создан глобальный Redux store с использованием Redux Toolkit
- Настроены слайсы для управления состоянием ингредиентов, конструктора бургера, пользователя и ленты заказов
- Реализована типизация для RootState и AppDispatch

### 3. Загрузка ингредиентов
- Реализована асинхронная загрузка ингредиентов с сервера через API
- Интеграция данных ингредиентов в компоненты через Redux store
- Настроены селекторы для получения ингредиентов в компонентах

### 4. Роутинг
- Настроен роутинг приложения с использованием React Router
- Созданы маршруты для всех страниц приложения
- Реализованы защищенные маршруты для страниц профиля

### 5. Функционал конструктора бургера
- Реализовано добавление ингредиентов в конструктор бургера
- Добавлена возможность перемещения ингредиентов в конструкторе
- Реализовано удаление ингредиентов из конструктора
- Настроено отображение счетчиков ингредиентов
- Реализована логика оформления заказа через API

### 6. Авторизация
- Настроена авторизация пользователя через API
- Реализованы формы регистрации, входа, восстановления и сброса пароля
- Добавлены защищенные маршруты, доступные только авторизованным пользователям
- Реализовано автоматическое обновление токена доступа

### 7. Лента заказов
- Реализована загрузка и отображение ленты заказов
- Настроено отображение заказов пользователя в профиле
- Интегрирована лента заказов с Redux store

## Важно:

Для корректной работы запросов к серверу необходимо добавить переменную BURGER_API_URL в окружение. Сама ссылка находится в файле `.env.example`.
